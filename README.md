# DWBI - Data Warehouse Business Intelligence System

## 📊 سیستم مدیریت منابع زیرساخت DWBI

یک سیستم جامع مدیریت منابع زیرساخت با قابلیت‌های پیشرفته برای محیط‌های آفلاین.

## ✨ ویژگی‌های کلیدی

### 🔐 سیستم احراز هویت
- **احراز هویت چندسطحی**: Admin, Editor, User
- **مدیریت مجوزها**: کنترل دسترسی دقیق بر اساس نقش
- **جلسه امن**: Session management با localStorage

### 📋 مدیریت ماژول‌ها
- **ایجاد ماژول‌های سفارشی**: امکان تعریف ستون‌های دلخواه
- **ویرایش زنده**: امکان ویرایش مستقیم در جدول
- **جستجوی پیشرفته**: جستجو در تمام فیلدها
- **مدیریت ردیف و ستون**: افزودن، حذف و ویرایش

### 📊 قابلیت‌های اکسل
- **آپلود فایل اکسل**: پشتیبانی از فرمت‌های .xlsx و .xls
- **دانلود اکسل**: خروجی داده‌ها به فرمت اکسل
- **گزارش‌گیری HTML**: تولید گزارش‌های حرفه‌ای

### 💾 سیستم پشتیبان‌گیری
- **پشتیبان‌گیری خودکار**: هنگام ورود کاربران Admin
- **پشتیبان‌گیری دستی**: امکان دانلود بکاپ در هر زمان
- **بازیابی داده‌ها**: بازگردانی از فایل‌های بکاپ

### 👥 مدیریت کاربران
- **ایجاد کاربران جدید**: با نقش‌های مختلف
- **ویرایش اطلاعات کاربران**: تغییر نام و نقش
- **تغییر رمز عبور**: مدیریت امنیت کاربران

## 🚀 نصب و راه‌اندازی

### پیش‌نیازها
- Node.js (نسخه 20 یا بالاتر)
- Windows Service Manager (NSSM) برای نصب سرویس

### نصب سریع
```bash
# کلون کردن پروژه
git clone https://github.com/yourusername/dwbi-system.git
cd dwbi-system

# اجرای سرور
node server.js
```

### نصب به عنوان Windows Service
```bash
# اجرای فایل نصب‌کننده
install.bat
```

## 📁 ساختار پروژه

```
dwbi-system/
├── server.js              # سرور اصلی Node.js
├── index.html             # رابط کاربری اصلی
├── script.js              # منطق فرانت‌اند
├── style.css              # استایل‌های CSS
├── data.json              # پایگاه داده JSON
├── install.bat            # نصب‌کننده Windows Service
├── logs/                  # فایل‌های لاگ
│   ├── output.log
│   └── error.log
└── backup/                # پوشه بکاپ‌ها
```

## 🎯 کاربردها

- **مدیریت سرورها**: ثبت اطلاعات سرورها، IP، وضعیت
- **مدیریت شبکه**: تجهیزات شبکه، سوئیچ‌ها، روترها
- **مدیریت نرم‌افزار**: لیسانس‌ها، نسخه‌ها، انقضا
- **مدیریت سخت‌افزار**: تجهیزات فیزیکی، سریال‌ها
- **مدیریت تسک‌ها**: پیگیری کارها و وظایف

## 🔒 امنیت

- **محافظت از XSS**: تمام ورودی‌ها امن‌سازی می‌شوند
- **کنترل دسترسی**: مجوزهای دقیق بر اساس نقش
- **Session Security**: مدیریت امن جلسات کاربری
